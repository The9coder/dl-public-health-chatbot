# AI-Driven Public Health Chatbot
Deep Learning mini project for disease awareness.

## Structure
- notebooks/: Jupyter/Colab notebooks
- data/: datasets
- models/: trained models (.h5/.pth)
- src/: Python modules (preprocessing, training, evaluation)

## How to Run
1. Install requirements: `pip install -r requirements.txt`
2. Run EDA: `notebooks/eda_pipeline.ipynb`
3. Train baseline: `src/train_baseline.py`
4. Train DL model: `src/train_dl.py`
